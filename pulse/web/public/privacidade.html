Política de privacidade do Pulse

Última atualização: 30 de setembro de 2026 · English summary

O Pulse é uma aplicação pessoal e familiar (Web e Android) que reúne, num só sítio, as tarefas, as contas, as compras, os bilhetes de comboio e, se a pessoa o autorizar, o Calendário e o Gmail. Não é um serviço comercial nem está aberto ao público: as contas são criadas pelo administrador para pessoas da casa.

Que dados do Google o Pulse usa

Só se a própria pessoa ligar a sua conta Google, em Definições › Contas Google, e só para o que escolher (Gmail, Calendário ou ambos):

  • Gmail (âmbito gmail.modify): ler o remetente, o assunto e o texto das mensagens para mostrar as importantes por ler, e marcar como lida, arquivar ou pôr uma estrela. O Pulse nunca envia, responde, reencaminha nem apaga mensagens.
  • Calendário (calendar.events e calendar.readonly): ler os eventos e criar, alterar ou apagar eventos quando a pessoa o pede no Pulse.
  • O nome e o e-mail da conta Google, para mostrar qual conta está ligada.

Como são guardados e usados

  • Só o necessário para a função pedida. Os dados do Gmail e do Calendário são lidos quando a pessoa abre o Pulse e não são copiados para uma base de dados: ficam apenas na memória do servidor, durante o pedido e numa cache de poucos minutos.
  • O que fica guardado é a autorização do Google (um «refresh token»), cifrada, no servidor pessoal do administrador (um Raspberry Pi em casa). Nunca é enviada para a aplicação Web nem para o telemóvel.
  • Os dados não são vendidos, partilhados com terceiros, usados para publicidade, nem usados para treinar modelos de inteligência artificial, e nenhuma pessoa os lê manualmente.
  • A utilização e a transferência de informação recebida das APIs do Google seguem a Política de Dados do Utilizador dos Serviços de API do Google, incluindo os requisitos de utilização limitada.

Como retirar o acesso e apagar

  • Em Definições › Contas Google, a pessoa pode remover a conta: o Pulse apaga a autorização guardada.
  • Também se pode revogar o acesso em myaccount.google.com/permissions.
  • Para apagar toda a conta do Pulse e os dados associados, basta pedir ao administrador.

Outros dados do Pulse

O Pulse guarda também os dados que a pessoa lá regista (por exemplo peso, tarefas, compras, contas), no mesmo servidor pessoal, acessíveis só à própria pessoa e ao administrador. Não usa ferramentas de análise nem publicidade.

English summary

Pulse is a private household app. If a user connects their Google account, Pulse reads Gmail messages (and can mark them read, archive or star them — it never sends or deletes email) and reads/creates/edits Calendar events, only on that user's request. Gmail and Calendar data are not copied to any database (they only live in server memory while being served, with a cache of a few minutes): only an encrypted Google authorization token is kept, on the administrator's own server. Data is never sold, shared, used for advertising or to train AI models, and Pulse's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Users can remove the account in Pulse settings or revoke access at myaccount.google.com/permissions. Contact: pereirabmd@gmail.com.
